# Jarvis — masaüstü yerel çalışma alanı

Bu paket **tamamen PC’de** çalışır. Cloud / Cursor agent masaüstüne yazamaz.

## Tek adım (Windows)

1. Bu `Jarvis-1.0` klasörünü PC’ye indir (zip veya git pull).
2. `YEDEKLE_MASAUSTU.bat` çift tıkla.
3. Oluşur: `%USERPROFILE%\Desktop\Jarvis`
4. Yerel git deposu açılır (uzak sunucu yok).
5. Bağımlılıklar kurulur, panel açılır: http://127.0.0.1:8787

Repo kökünden: `TASI_MASAUSTUNE_JARVIS.bat`

## Sonra her gün

```
Desktop\Jarvis\BASLAT.bat
```

Artık cloud’a gerek yok — sadece bu klasörde çalış.
