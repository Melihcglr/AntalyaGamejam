- **`Jarvis-1.0/`** — Bağımsız Jarvis paketi. Masaüstüne yerel yedek: `YEDEKLE_MASAUSTU.bat` → `Desktop\Jarvis 1.0` (+ yerel git, bulutsuz).
- **`proje-0-jarvis/`** — Aynı asistanın önceki kopyası.
